
# Sea Imposteur V5

Prototype multijoueur Node.js + Express + Socket.IO.

## Lancer en local

```bash
npm install
npm start
```

Puis ouvrir `http://localhost:3000`.

Pour tester le multijoueur : ouvre plusieurs onglets/fenêtres avec le même code de cabine.

## V5 inclus

- Cabines privées avec code.
- 3 à 20 joueurs.
- Avatars pirates.
- Prêt / lancement par le capitaine.
- Réglage de la durée de quête : 10 / 15 / 20 / 30 / 45 / 60 min.
- Réglage de l'intervalle entre réunions : 4 / 5 / 7 / 10 / 15 / 20 / 30 min.
- Réglage de la durée des réunions : 39 sec / 1 / 2 / 3 / 4 min.
- Espion activable/désactivable.
- Rôles serveur : Pirate, Imposteur, Espion.
- Consultation du rôle personnel.
- Quête commune unique.
- Objectif secret d'Imposteur lié à la quête.
- Pouvoir de l'Espion : révéler une mission d'Imposteur, sans son identité.
- Réunions et votes.
- Fin de partie selon quête, élimination des Imposteurs ou temps écoulé.
- Aucun événement aléatoire.

## Important

Le dossier est un prototype fonctionnel V5. Les illustrations finales peuvent ensuite être remplacées par des assets originaux plus détaillés tout en conservant l'interface et la direction artistique pirate de la maquette fournie.
