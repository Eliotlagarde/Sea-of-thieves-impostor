# 🏴‍☠️ Sea of Thieves — L’Imposteur V3

Version V3 du jeu multijoueur :
- design pirate inspiré de la maquette validée : parchemins, cartes, pièces, bois, lanternes et animations légères ;
- connexion/lobby sobres et responsives ;
- 3 à 20 joueurs, 1 à 3 imposteurs ;
- intervalle entre réunions configurable et durée de réunion configurable ;
- réunions automatiques, vote secret puis résultats sans révéler qui a voté pour qui ;
- missions variées sans mini-puzzles ;
- événements aléatoires ;
- journal de bord personnel et notes ;
- écran de fin avec rôles, statistiques et titres ;
- easter eggs, dont le coffre photo ;
- musique locale conservée ;
- sons supplémentaires non inclus pour cette version.

## Lancer
`npm install` puis `npm start`.
