# Sea of Thieves : L’Imposteur — V4

Version 4 du jeu web multijoueur pirate.

## Stack
- Node.js
- Express
- Socket.IO
- HTML/CSS/JavaScript
- Compatible Render

## Nouveautés V4
- Quête commune en 5 missions
- Missions secrètes distinctes pour les Imposteurs
- Nouveau rôle spécial : l’Espion
- Pouvoir unique de l’Espion : révéler un objectif d’Imposteur sans révéler son identité
- Conditions de victoire/défaite liées à la quête et au temps
- Vote secret avec détection du joueur ayant reçu le plus de votes, sans révéler les votants
- Événements intégrés au journal/interface, sans notification flottante
- Refonte graphique pirate : bois, parchemin, bronze, or vieilli, mer, carte maritime et lanternes
- Interface responsive PC/tablette/mobile avec navigation basse sur petit écran
- Coffre de rôle et easter egg conservés
- Musique locale uniquement

## Déploiement Render
Root Directory : `Sea_of_Thieves_Imposteur_V3`
Build Command : `npm install`
Start Command : `npm start`
